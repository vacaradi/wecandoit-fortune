# 금칙어 목록

AI는 놔두면 반드시 뻔한 문장으로 회귀합니다.
아래 표현이 결과물에 나오면 **그 세트를 통째로 다시 쓰세요.**
`scripts/validate-content.mjs` 가 자동으로 걸러내지만, 쓰는 단계에서 피하는 게 우선입니다.

## 1. 운세 클리셰 — 즉시 재작성

```
좋은 일이 생길 것입니다
노력한 만큼 결과가 따릅니다
귀인을 만날 수 있습니다
건강에 유의하세요
긍정적인 마음가짐이 중요합니다
새로운 기회가 찾아옵니다
인간관계에 신경 쓰세요
금전운이 상승합니다
뜻밖의 행운이
차분하게 대처하면
서두르지 말고
욕심을 buried 금물
```

**왜 금지인가**: 아무 날에나 붙여도 말이 됩니다. 즉 아무 정보도 없습니다.

## 2. 추상어 — 구체적 장면으로 바꾸세요

| 금지 | 대신 |
|---|---|
| 대인관계 | 단톡방, 옆자리, 모임 |
| 재물운 | 카드값, 장바구니, 용돈 |
| 건강 | 목이 뻐근함, 세 시쯤 힘 빠짐 |
| 업무 | 회의, 메일, 보고서 |
| 학업 | 수행평가, 시험 전날, 급식 |
| 활력 | 눈이 감김, 이불에서 못 나옴 |

## 3. 문체 금지

```
✕  ~하리라 / ~할지어다        (예언조)
✕  ~할 수도 있습니다           (김 새는 표현)
✕  ~하시길 바랍니다            (기원조)
✕  느낌표 !
✕  이모지 ✨🔮💫🌙⭐
✕  물결표 ~ (문장 끝)
✕  ㅋㅋ, ㅎㅎ, ㅠㅠ
```

## 4. 안 웃긴 개그 패턴

```
✕  아재개그 (말장난, 동음이의어)
✕  "~라고 쓰고 ~라고 읽는다"
✕  "레전드", "충격", "실화냐"  (밈 유통기한)
✕  유행어 (6개월이면 촌스러워짐)
```

**병맛은 유행어가 아니라 상황에서 나옵니다.**

## 5. 반복 금지 — 하루 안에서

같은 날 12띠 안에서 아래가 겹치면 안 됩니다.

- 같은 소재 (알람이 두 띠에 나오면 안 됨)
- 같은 명언 인물 (아리스토텔레스가 두 번 나오면 안 됨)
- 같은 부적 이름
- 같은 넷플릭스 작품
- 같은 문장 구조 3개 이상 (`"~하려는 순간 ~합니다"` 가 네 번 나오면 지루함)

## 6. 반복 금지 — 최근 30일

`content/pools/used-log.json` 을 확인하고 아래를 피합니다.

- 최근 **14일** 안에 쓴 소재
- 최근 **30일** 안에 쓴 명언
- 최근 **30일** 안에 쓴 넷플릭스 작품
- 최근 **21일** 안에 쓴 부적 이름

**지루함의 진짜 원인은 반복입니다.** 한 편 한 편이 재밌어도 일주일 만에 "또 편의점 얘기네"가 되면 끝입니다.
