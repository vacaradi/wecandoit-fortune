# 소재 풀

매일 새 운세를 쓰려면 소재가 계속 필요합니다.
아래 목록에서 **그날 쓸 소재를 골라 조합**합니다.
`content/pools/used-log.json` 을 먼저 확인해 **최근 14일에 쓴 소재는 제외**합니다.

## 쓰는 법

```
1. used-log.json 에서 최근 14일 소재 목록을 읽는다
2. 아래 풀에서 제외되지 않은 소재를 36개 고른다
3. 36세트에 하나씩 배정 (같은 날 중복 금지)
4. 생성 후 used-log.json 에 오늘 쓴 소재를 기록한다
```

## student — 학생 (~19세)

```
1교시에 졸음 / 급식 메뉴 / 수행평가 미룸 / 시험 전날 시작
사물함에 뭘 두고 옴 / 체육 시간에 비 옴 / 조별과제 연락 안 됨
용돈이 벌써 없음 / 학원 가는 길 / 친구가 먼저 갔음
숙제 파일이 안 열림 / 발표 차례가 다가옴 / 자리 바꾸기
매점 줄이 김 / 교복에 뭐가 묻음 / 단톡방이 조용함
버스에서 정류장을 지나침 / 시험 범위를 잘못 앎
```

**금지**: 성적·등수·입시 결과, 외모, 이성 교제, 술·담배

## worker — 직장·사회 (20~64세)

```
회의가 길어짐 / 5시 47분에 메일 옴 / 결재가 안 남
프린터가 안 됨 / 점심 메뉴 정하기 / 월급과 카드값
엘리베이터를 놓침 / 회식 2차 / 오타 난 보고서
휴가 신청 눈치 / 단톡방 오발송 / 자리 비운 사이 호출
커피값이 쌓임 / 출근길이 유난히 막힘 / 재택인데 더 바쁨
연락처를 잘못 저장함 / 이름을 못 외움 / 회의실이 겹침
```

**금지**: 특정 직급·직종 비하, 실직·해고 단정

## senior — 여유 (65세~)

```
새벽에 눈이 떠짐 / 낮잠이 길어짐 / 서랍 정리하다 사진 봄
저녁 메뉴가 안 정해짐 / 모임 날짜가 겹침 / 오랜만의 연락
리모컨이 안 됨 / 휴대폰 글씨가 작음 / 손주 선물 고르기
산책길에서 아는 사람 만남 / 병원 예약이 밀림
화분에 물 주는 걸 잊음 / 라디오에서 옛날 노래가 나옴
장 보러 갔다가 더 삼 / 계단보다 경사로가 편함
```

**금지**: 노화·기력 쇠퇴 비하, 치매·낙상·지병, "나이가 있으시니" 류

## 소재 배정 규칙

- 같은 날 36세트에 **같은 소재 두 번 금지**
- 같은 띠의 3개 연령대는 **주제는 통하되 장면은 완전히 달라야** 함
  ```
  쥐띠 student : 1교시 졸음
  쥐띠 worker  : 지각 확정 시각
  쥐띠 senior  : 새벽에 눈이 떠짐
  → 모두 '잠' 계열이지만 장면이 다름 (좋음)
  ```
- 풀에 없는 소재를 새로 만들어도 됩니다. 만들면 이 파일에 추가하세요.
