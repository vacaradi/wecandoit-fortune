# 안전 가이드 — 넘지 말아야 할 선

운세 콘텐츠는 사람의 하루에 영향을 줍니다.
재미가 목적이지만, 아래를 어기면 **서비스 자체가 위험해집니다.**
이 문서의 규칙은 재미보다 우선합니다.

## 1. 절대 금지 — 법적·윤리적 위험

### 의료
```
✕  병이 낫습니다 / 아플 것입니다
✕  이 음식을 먹으면 좋아집니다
✕  병원에 가지 않아도 됩니다
✕  특정 질병명 언급 (암, 우울증, 당뇨…)
```
건강 관련은 **"세 시쯤 기운이 빠집니다"** 수준의 컨디션 묘사까지만.

### 금전·투자
```
✕  투자하면 수익이 납니다
✕  주식/코인/부동산 매수·매도 시점 언급
✕  큰돈이 들어옵니다
✕  복권을 사세요
```
돈 이야기는 **"카드값이 빠져나갑니다"** 같은 생활 지출까지만.

### 예언·불행
```
✕  사고가 납니다
✕  누군가 떠납니다 / 이별합니다
✕  시험에 떨어집니다 / 합격합니다
✕  죽음, 사망, 장례 관련 일체
✕  이혼, 파혼, 실직 단정
```

### 종교·주술
```
✕  실제 종교 의식·기도문 모방
✕  "부적을 지니면 액운이 물러갑니다" 같은 실효 주장
✕  굿, 퇴마, 빙의 등 소재
```
부적은 **재미있는 기념품**입니다. 효험을 진지하게 주장하지 마세요.

## 2. 차별·비하 금지

```
✕  외모, 체중, 키
✕  학벌, 직업 귀천
✕  지역, 출신
✕  성별, 성적 지향
✕  나이 (늙었다, 어리다는 식의 비하)
✕  장애, 질환
✕  국적, 인종
```

**자기 비하는 허용, 타인 조롱은 금지.**
"오늘 당신은 굼뜹니다"는 괜찮습니다. "○○띠는 원래 게으릅니다"는 안 됩니다.

## 3. 오늘의 빌런 — 특히 조심

빌런은 **오늘따라 얄미운 사람**이지 나쁜 사람이 아닙니다.

```
좋음:  왜 이렇게 느리냐고 묻습니다
좋음:  "난 되던데?"라고 말합니다
좋음:  한밤중에 음식 사진을 보냅니다

나쁨:  당신을 무시합니다              ← 관계 악화 유발
나쁨:  뒤에서 험담합니다              ← 없는 갈등을 심음
나쁨:  당신을 싫어합니다              ← 불안 조성
```

**읽고 나서 실제 인간관계를 의심하게 만들면 실패입니다.**

## 4. 불안 조성 금지

재미와 불쾌는 다릅니다.

```
✕  오늘은 조심하지 않으면 큰일이 납니다
✕  가까운 사람을 믿지 마세요
✕  나쁜 일이 기다리고 있습니다
```

운세가 나쁜 날에도 **결말은 웃음이나 위로**로 끝나야 합니다.
"오늘 당신은 가장 성실한 사람이자 가장 억울한 사람입니다" — 이 정도가 최대치입니다.

## 5. 연령대별 추가 주의

### 학생 (`student`)
```
✕  성적, 등수, 입시 결과 언급
✕  외모·인기 관련
✕  술, 담배, 도박
✕  이성 교제 부추김
```
학교 소재는 **급식, 수행평가 미룸, 졸음, 버스** 수준으로.

### 시니어 (`senior`)
```
✕  노화, 기력 쇠퇴를 부정적으로 묘사
✕  치매, 낙상, 지병 언급
✕  "이제 나이가 있으시니" 류의 표현
✕  자식·손주와의 갈등 소재
```
**시니어 콘텐츠는 무시하지 않는 톤이 핵심입니다.**
기계를 못 다룬다는 식이 아니라 "오늘따라 안 된다"로 씁니다.

## 6. 명언 인용 규칙

```
✓  실존 인물의 실제 발언만
✓  출처가 불확실하면 아예 쓰지 않음
✕  없는 말을 지어내서 위인에게 붙이기
✕  정치인, 생존 인물의 발언
✕  종교 경전 인용
```

가짜 명언은 웃기지만 **캡처가 돌면 수습이 안 됩니다.**
확실하지 않으면 다른 명언을 고르세요.

## 7. 넷플릭스 추천 규칙

```
✓  실제 넷플릭스에 있는 작품만
✓  netflix.com/title/{id} 링크가 열리는지 확인
✕  19금·과도한 폭력물을 학생 연령대에 추천
✕  자살·자해 소재 작품 추천
```
