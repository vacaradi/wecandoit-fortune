# 톤 가이드 — 위캔두잇 오늘의 운세

## 이 서비스의 정체성

```
비주얼은 진지하고 고급스럽다  ×  텍스트는 웃기다
```

마법사 토끼 '위'가 우주에서 수정구를 들여다보고, 도사가 구름 위에서 두루마리를 펼칩니다.
그 진지한 화면에 **"냉장고가 닫히게 하소서"** 같은 문구가 뜹니다.
이 낙차가 이 서비스의 전부입니다. 비주얼까지 웃기면 그냥 싼 앱이 됩니다.

## 병맛 3요소

모든 운세 문구는 이 셋을 갖춰야 합니다.

| 요소 | 설명 | 예시 |
|---|---|---|
| **구체적 상황** | 누구나 겪는 장면을 딱 집어서 | "알람은 여섯 번 울렸고" |
| **진지한 척** | 사소한 일을 거창한 단어로 포장 | "우주가 자아성찰의 시간을 하사한 것입니다" |
| **자폭 마무리** | 확률 제시, 급 현실 자각, 예상 밖 결론 | "오늘 가장 빠르게 움직인 순간은 이불에서 나온 3초였습니다" |

## 왜 기존 운세는 지루한가

문제는 톤이 진지해서가 아니라 **내용이 추상적**이기 때문입니다.

```
지루함:  "오늘은 대인관계에 신경 쓰면 좋은 일이 있겠습니다"
재미:    "책을 편 순간 누군가 같이 하자고 합니다"
```

**추상 → 구체**로 바꾸는 것이 이 서비스의 핵심 기술입니다.
"좋은 일", "노력", "귀인" 같은 단어가 나오면 그 문장은 실패입니다.

## 문장 규칙

### 길이
- 한 줄은 **공백 포함 12~22자**. 화면에서 두 줄로 넘어가면 안 됩니다.
- 한 단락은 **2줄**. `\n` 하나로 나눕니다.
- 본문은 **2~3단락**.

### 어미
- **`~습니다` / `~입니다`로 통일**합니다. 예언조(`~하리라`), 반말, 물음표 남발 금지.
- 단정적으로 씁니다. "~할 수도 있습니다"는 김이 샙니다. "~합니다"로 끊으세요.

### 인칭
- 사용자는 **"당신"**. "그대", "귀하", "~님" 쓰지 않습니다.

### 금지
- 이모지 (✨🔮💫 등) 절대 사용 금지. 텍스트로 분위기를 만들지 못했다는 뜻입니다.
- 느낌표 금지. 병맛은 담담할수록 웃깁니다.
- 말줄임표(…) 남용 금지. 한 세트에 1개까지.

## 핵심 한 줄 (lead)

운세 화면 맨 위에 명조체로 크게 뜨는 문장입니다.

- **10~18자**
- 그 자체로 오늘이 어떤 날인지 알 수 있어야 합니다
- 본문의 요약이 아니라 **선언**입니다

```
좋음:  알람은 오늘도 이깁니다
좋음:  배터리가 3%입니다
좋음:  "딱 하나만"은 거짓입니다
나쁨:  오늘은 아침에 조심하세요        ← 조언이지 선언이 아님
나쁨:  당신의 하루는 바쁘게 흘러갑니다  ← 추상적
```

## 지수 (metric)

- 이름은 **"○○지수"** 형태, 3~6자
- **높을수록 오늘 그 기운이 강하다**는 방향으로 통일합니다. 예외 없습니다.
- 낮아야 나쁜 지표(출근지수 8)는 만들지 마세요. 뒤집어서 이름을 바꾸세요(지각지수 92).
- 값은 그날 운세의 강도에 맞춥니다. 전부 90 이상이면 의미가 없습니다.
  하루 12띠 중 **90+는 3~4개, 40 미만은 1~2개** 정도로 분포시키세요.

## 그래서 오늘은 (tip)

운세를 읽고 나서 **실제로 써먹을 것 하나**를 줍니다.

- **2줄**
- 오늘 당장 할 수 있는 행동이어야 합니다
- "긍정적으로 생각하세요" 같은 정신론 금지
- 웃기려 하지 말고 담담하게. 앞에서 실컷 웃겼으니 여기선 진짜 도움을 줍니다

```
좋음:  알람을 5분이 아니라 20분 앞으로 당겨두세요.
      오늘은 그 20분이 하루 전체를 결정합니다.

나쁨:  오늘은 조금 더 부지런해지면 좋겠습니다.
      마음가짐이 중요합니다.
```

## 명언 해설 (qn)

**진짜 명언 × 병맛 해설**의 낙차가 웃음 포인트입니다.

- 명언 원문은 **실존 인물의 실제 발언**만 씁니다. 지어내면 안 됩니다.
- 해설에서 위인을 **친근하게 끌어내립니다**. "루소 형님도 읽씹당해본 게 분명합니다"
- **2줄**

```
좋음:  파스퇴르는 보조배터리를 미리 충전해두는 사람이었을 겁니다.
      그래서 위인이 된 거예요.
```

## 오늘의 사람 (ally / foe)

- 다른 띠 하나씩을 아군과 빌런으로 지정합니다
- **자기 띠는 지정하지 않습니다**
- 빌런은 악당이 아니라 **오늘따라 얄미운 사람**입니다. 인신공격 금지
- 각 **1줄**

```
아군 소띠   느긋해서 당신을 재촉하지 않습니다
빌런 말띠   왜 이렇게 느리냐고 묻습니다
```

## 부적

- 이름은 **"○○부"** 형태, 4~7자. 한자어처럼 들리게
- 문구는 **"~하소서"** 로 끝나는 기원문, 8~14자
- 이름이 진지할수록 웃깁니다. "다이어트내일부", "냉장고봉인부"

## 연령대별 현장 (scene)

일상 운세는 모두에게 공통, 그 위에 나이에 맞는 한 겹을 얹습니다.

| 대상 | 나이 | 소재 |
|---|---|---|
| `student` | ~19세 | 학교, 시험, 급식, 용돈, 친구, 학원 |
| `worker` | 20~64세 | 출근, 회의, 메일, 월급, 상사, 회식 |
| `senior` | 65세~ | 건강, 모임, 정리, 손주, 산책, 병원 |

**절대 규칙**: 학생에게 결재·월급 이야기, 시니어에게 회의·상사 이야기가 나가면 안 됩니다.
같은 띠라도 연령대마다 완전히 다른 장면을 씁니다.

## 톤 검사 — 이 중 하나라도 걸리면 다시 쓰세요

- [ ] "좋은 일", "노력", "귀인", "긍정적", "마음가짐" 이 들어갔다
- [ ] 이모지나 느낌표가 있다
- [ ] 한 줄이 22자를 넘는다
- [ ] 어미가 `~습니다`가 아니다
- [ ] 상황이 구체적이지 않고 뭉뚱그려져 있다
- [ ] 읽고 나서 "그래서?"가 남는다
- [ ] 웃긴 부분이 하나도 없다
- [ ] 연령대에 안 맞는 소재가 들어갔다
