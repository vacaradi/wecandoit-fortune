# 출력 형식 명세

## 하루치 = 36세트

```
12띠  ×  3연령대(student / worker / senior)  =  36세트
```

**같은 띠라도 연령대가 다르면 본문이 완전히 달라야 합니다.**
2015년생 쥐띠와 1972년생 쥐띠가 같은 문장을 보면 안 됩니다.

### 연령대 판정

```js
age = 올해 - 출생연도
age < 20   → student   (~19세)
age < 65   → worker    (20~64세)
그 외       → senior    (65세~)
```

### 띠 판정

```js
signIndex = ((출생연도 - 4) % 12 + 12) % 12
// 0=쥐 1=소 2=범 3=토끼 4=용 5=뱀 6=말 7=양 8=원숭이 9=닭 10=개 11=돼지
```

## 파일 위치

```
content/daily/YYYY/MM/YYYY-MM-DD.json
```

## 필드별 제약

| 필드 | 제약 |
|---|---|
| `lead` | 10~18자, 마침표 없음 |
| `body[]` | 2~3개 단락. 각 단락 `\n` 1개. 한 줄 12~22자 |
| `flow` | 정확히 4개. 시간대는 `아침 낮 저녁 밤` 고정 |
| `flow[n][1]` | 1~4 정수. 하루가 전부 1이거나 전부 4면 안 됨 |
| `stats` | 정확히 4개. 항목명 `컨디션 재물운 인연운 집중력` 고정 |
| `score` | 하루 36세트 중 90+ 는 8~12개, 40미만은 3~6개 |
| `tip` | 2줄. 오늘 당장 할 수 있는 행동 |
| `quote.text` | 실존 인물의 실제 발언만 |
| `talisman.name` | ○○부, 4~7자 |
| `talisman.phrase` | ~하소서, 8~14자 |
| `netflix.id` | netflix.com/title/{id} 가 실제로 열려야 함 |

## aura 색상 팔레트

`score`와 무관하게 그날 분위기에 맞춰 고릅니다. 이 6개 중에서만.

```
#D6B24C  금색     — 기운이 강하고 좋은 날
#7FD0FF  하늘색   — 맑고 가벼운 날
#4A47A0  남보라   — 차분하거나 처지는 날
#7B4AA0  보라     — 묘하게 꼬이는 날
#C0533A  주홍     — 답답하거나 억울한 날
#3B7A5E  청록     — 기다림, 인내의 날
```

## 하루 안에서 지켜야 할 분포

36세트 전체를 놓고 확인합니다.

- 명언 인물 **중복 0** (36명 전부 달라야 함)
- 넷플릭스 작품 **중복 0**
- 부적 이름 **중복 0**
- 같은 소재가 두 세트에 나오면 안 됨
- `aura` 는 6색이 고르게 분포

## 생성 후 필수 검증

```
node scripts/validate-content.mjs content/daily/2026/08/2026-08-13.json
```

통과 못 하면 배포하지 않습니다.
